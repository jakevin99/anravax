# Anivax

Health information system for animal bite clinics: staff web app, REST API, and optional patient mobile app.

| Package | Description |
|---------|-------------|
| [`anivax/`](anivax/) | Staff web UI (React Router 7) + Express API + SQLite |
| [`anivax-mobile/`](anivax-mobile/) | Patient-facing React Native app (OTP login, queue, doses, documents) |

Start with the [Anivax web README](anivax/README.md) for installation, API, and deployment. Staff procedures are documented in [anivax/docs/STAFF-ROLES-USER-MANUAL.md](anivax/docs/STAFF-ROLES-USER-MANUAL.md).
